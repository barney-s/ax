## Execution & Attempt Log

### Attempt 1: Initial Rollout & Controller ConfigMap Key Mismatch
- **What Failed:** `ax-controller` deployment rollout timed out waiting for condition.
- **Evidence:** `kubectl describe pod ax-controller-...` showed event: `MountVolume.SetUp failed for volume "servicedns-ca" : configmap references non-existent config key: ca.pem`.
- **What was changed:** Discovered that the `ateapi-ca` ConfigMap generated by Substrate Helm chart v0.0.12 provides the certificate under key `ca.crt` rather than `ca.pem`. Updated `deploy/ax-controller.yaml` to project `ca.crt` to path `trust-bundle.pem`.

### Attempt 2: Dynamic Protobuf Compatibility & ActorTemplate CRD Schema
- **What Failed:** During initial task creation, `ax-controller` encountered:
  1. `rpc error: code = InvalidArgument desc = [actor.actor_template_namespace: Required value, actor.actor_template_name: Required value]`
  2. `rpc error: code = FailedPrecondition desc = ActorTemplate ax-system/default-template not found`
- **Evidence:** Task status condition reported `ActorCreationFailed`.
- **What was changed:**
  1. Updated `internal/substrate/client.go` to use `google.golang.org/protobuf/encoding/protowire` to dynamically inject fields 2 (`actor_template_namespace`) and 3 (`actor_template_name`) on `ateapipb.Actor` messages for backward compatibility with Substrate 0.0.12.
  2. Created `default-template` `ActorTemplate` resources in `ax-system` and `default` namespaces pinned to the exact image digest (`@sha256:af980a6c...`) of the built `ax-task-runner`.
  3. Integrated automatic digest resolution and `ActorTemplate` application into `deploy.sh`.

## Deviations from the Runbook

1. **Substrate Helm Chart v0.0.12 Deployment**: Used published Helm charts (`oci://ghcr.io/kagent-dev/substrate/helm/substrate-crds` and `substrate` v0.0.12) to deploy Substrate cleanly onto GKE standard without requiring alpha `ClusterTrustBundle` APIs.

3. **CA Certificate ConfigMap Key**: Configured `deploy/ax-controller.yaml` to project `ca.crt` from the replicated `ateapi-ca` ConfigMap to `/run/servicedns-ca/trust-bundle.pem`.
4. **Protobuf Wire Injection**: Injected wire fields 2 and 3 into `Actor` gRPC payloads in `internal/substrate/client.go` to ensure backwards compatibility with Substrate 0.0.12.
5. **ActorTemplate Image Pinning**: Applied `default-template` `ActorTemplate` resources with explicit container image digest pins (`@sha256:...`) required by Substrate snapshotting validations.
