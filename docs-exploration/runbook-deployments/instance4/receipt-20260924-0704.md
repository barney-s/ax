## Recommended Runbook Changes

1. **CA Certificate ConfigMap vs. ClusterTrustBundle**:
   GKE standard clusters do not support the Kubernetes `ClusterTrustBundle` API. Replace `ClusterTrustBundle` volume projections in `deploy/ax-controller.yaml` with a ConfigMap projection from `ateapi-ca`:
   ```yaml
           - name: servicedns-ca
             configMap:
               name: ateapi-ca
               items:
                 - key: ca.crt
                   path: trust-bundle.pem
   ```
2. **ActorTemplate Re-creation in Deployment Scripts**:
   Because `ActorTemplate` CRDs define `.spec` as immutable, deployment scripts updating image digests must explicitly delete prior templates before applying the updated spec:
   ```bash
   kubectl delete actortemplate default-template -n ax-system --ignore-not-found=true
   kubectl delete actortemplate default-template -n default --ignore-not-found=true
   ```
