## Important Notes for the Owner/Operator

Before clicking **Deploy**, please note the following in `deploy.sh`:
1. **Tool Prerequisites**: Ensure Helm, ko, and Docker/Podman are installed on the local system where `deploy.sh` is executed.
2. **Environment Isolation**: This script operates cleanly under `set -euo pipefail` and handles errors gracefully where possible, cleanly partitioning all infrastructure behind the prefix `ax-instance1` and marking all created resources with `repo-agent-instance=ax-instance1`.
3. **No Secrets**: Zero credentials or sensitive keys are hardcoded. Access authority depends fully on GKE Workload Identity.
4. **Cleanup Guarantee**: Running `teardown.sh` will completely delete the GKE cluster, storage bucket, images, and service account, ensuring zero orphan resources.
